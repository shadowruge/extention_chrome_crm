# Política de Privacidade — WhatsApp CRM

**Última atualização:** 17 de novembro de 2026  
**Responsável:** InfoDevBrasil — [infodevbrasil@gmail.com](mailto:infodevbrasil@gmail.com)

Esta extensão é independente e não é afiliada, patrocinada ou aprovada pela Meta ou pelo WhatsApp.

## Dados tratados

Quando você usa o CRM, a extensão armazena neste perfil do navegador:

- nomes e telefones de clientes cadastrados;
- etiquetas atribuídas aos clientes;
- respostas rápidas salvas;
- anotações que você escrever no calendário, com a data escolhida;
- contadores de atendimentos por cliente; e
- registros diários de conversas abertas pelo CRM.

O histórico usado no gráfico de frequência é mantido por até 90 dias. Os contadores por cliente permanecem até você apagar o cliente ou os dados.

## Onde os dados ficam

Os dados são mantidos no armazenamento local da extensão, no perfil do navegador. O MVP não os envia à InfoDevBrasil nem a um servidor próprio. O armazenamento não tem senha nem criptografia própria da extensão; proteja seu dispositivo e seu perfil do navegador.

## Integração com o WhatsApp Web

Quando você escolhe abrir uma conversa, o número do cliente é incluído no endereço do WhatsApp Web para localizar o contato. O WhatsApp Web recebe esse número e trata a navegação conforme suas próprias políticas.

Ao inserir uma resposta rápida, a extensão lê localmente o texto atual do campo de mensagem para evitar duplicação e insere a resposta para você revisar. A extensão não envia mensagens automaticamente nem coleta o conteúdo do histórico de conversas.

## Permissões

A extensão usa o armazenamento local do navegador e acessa o domínio `https://web.whatsapp.com/` para oferecer respostas rápidas e abrir conversas iniciadas por você. A interface lateral é fornecida pelas APIs de extensão do navegador.

## Retenção e controle

Os dados permanecem no perfil local até você apagá-los, remover os dados da extensão ou desinstalá-la. Na seção **Privacidade**, você pode:

- exportar uma cópia JSON dos dados do CRM, incluindo as anotações do calendário; e
- apagar os dados do CRM e revogar o consentimento.

A exportação contém dados pessoais; guarde o arquivo com segurança.
