Aviso de Privacidade

Responsável: InfoDevBrasil — infodevbrasil@gmail.com.

Esta extensão é independente e não é afiliada, patrocinada ou aprovada pela Meta ou pelo WhatsApp.

Dados tratados

Quando você usa o CRM, a extensão armazena neste perfil do navegador os nomes e telefones de clientes que você cadastrar, etiquetas, respostas rápidas, contadores por cliente e registros diários de conversas abertas pelo CRM. O histórico usado no gráfico de frequência é mantido por até 90 dias; os contadores por cliente permanecem até você apagar o cliente ou os dados. Esses dados ficam no armazenamento local da extensão e não recebem criptografia própria; proteja o perfil e o dispositivo.

Integração com o WhatsApp Web

Ao abrir uma conversa, o telefone escolhido é incluído no endereço do WhatsApp Web para localizar o contato. Ao inserir uma resposta rápida, a extensão lê localmente o texto atual do campo para evitar duplicação e insere a resposta para revisão e envio manual. A extensão não envia mensagens automaticamente nem coleta o conteúdo do histórico de conversas.

Compartilhamento e transmissão

O MVP não transmite a lista de clientes, respostas ou relatórios à InfoDevBrasil ou a um servidor próprio. O WhatsApp Web recebe o número quando você escolhe abrir uma conversa e trata essa navegação conforme as próprias políticas do serviço.

Retenção e controle

Os dados permanecem no perfil local do navegador até você apagá-los, remover os dados da extensão ou desinstalá-la. Use a seção Privacidade para exportar uma cópia JSON ou apagar os dados do CRM. A exportação contém dados pessoais; guarde-a com segurança.

Permissões

A extensão usa o armazenamento local para persistir seus dados, a API do painel lateral para a interface e acesso ao domínio do WhatsApp Web para oferecer respostas rápidas e abrir conversas iniciadas por você.
